# Innovera Linked Agents Prototype

A deterministic, presentation-ready demo of an Orchestrator Agent linking Market, Product, and Competitive specialists around a fictional European coffee market-entry decision.

All research, scores, sources, and recommendations are synthetic fixtures. The app makes no runtime network requests.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite. Use the primary presenter action, Space, or Right Arrow to advance the guided flow.

## Verify

```bash
npm run typecheck
npm test
npm run build
```
